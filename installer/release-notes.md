**Install:** download `SunbeamSetup.exe` and run it. It needs no administrator
rights and asks one thing: whether Sunbeam starts with Windows. Sunbeam then
starts, and its settings open once. Remove it under Settings, Apps.

**Without installing:** `Sunbeam.exe` alone runs from any folder.

Windows may warn that the file comes from an unknown publisher, because it is
not signed: choose "More info", then "Run anyway".

Requires Windows 10 or 11 (64-bit) and a graphics card with Direct3D 11.
